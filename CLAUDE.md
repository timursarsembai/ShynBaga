# ShynBaga

Состояние проекта, решения владельца, знания о Каспи и планы: `docs/STATUS.md`. Прочитай его перед работой и обновляй, когда что-то меняется.

- Секреты только в `.env`, в git его нет. Репозиторий публичный.
- После каждого изменения кода: ревью диффа, тесты, коммит, пуш.
- Тесты: `docker build -t shynbaga . && docker run --rm --network host --env-file .env --entrypoint python shynbaga -m pytest -q`.
- Выкатка `docker compose up -d --build` безопасна: сборщик не начнёт обход заново, если с начала прошлого прошло меньше 6 часов.
